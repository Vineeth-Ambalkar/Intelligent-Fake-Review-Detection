# Intelligent Fake Review Detection — Using Purchase & Return Behaviour

A working proof-of-concept for the idea in your slides: most fake-review
detectors look at review **text only**. This system additionally looks at
what actually happened to the product — was it **returned**, and **why** —
and treats a mismatch (glowing review + a quality-related return) as a
contributing signal rather than absolute proof.

This matches the Problem Statement / Objectives / Workflow slides exactly.

## What's included

```
fake_review_detection/
├── data/
│   └── generate_dataset.py     # simulates purchases + returns + reviews (4,000 rows)
├── ml/
│   ├── feature_extraction.py   # NLP sentiment features + behavioural features
│   ├── train_model.py          # trains & evaluates the ML model
│   ├── predict.py              # real-time prediction on new reviews
│   ├── model.joblib            # trained model (generated by train_model.py)
│   └── evaluation_report.json  # accuracy / precision / recall / feature importance
└── demo.html                   # interactive front-end demo (open in any browser)
```

## Running the ML pipeline

```bash
pip install pandas numpy scikit-learn joblib
python3 data/generate_dataset.py     # creates data/reviews_dataset.csv
python3 ml/train_model.py            # trains model, prints metrics, saves model.joblib
python3 ml/predict.py                # runs 4 example reviews through the trained model
```

Sample output from `train_model.py` (gradient-boosted trees, an
XGBoost-equivalent available offline):

- Accuracy: **94%**, ROC-AUC: **0.91**
- Precision/recall on the "suspicious" class: **0.86 / 0.79**
- Top feature by far: **positive review after a quality-related return**
  (77% of the model's decision weight) — exactly the signal described in
  the Problem Statement.

## Running the interactive demo

Just open `demo.html` in any web browser — no server or install needed.
Fill in a review's text, star rating, and return details, and it will:

1. Extract the same NLP + behavioural features described above
2. Score them with a lightweight version of the trained model's logic
3. Show a **Genuine / Suspicious** verdict with a probability
4. Break down exactly which signals drove that verdict — an early version
   of the "explainable AI dashboard" from your Future Enhancements slide

Try these to see the system in action:
- 5-star glowing text + returned for "defective" → flagged **Suspicious**
- 1-star negative text + returned for "defective" → stays **Genuine**
  (text and behaviour agree — an honest, consistent unhappy customer)
- 5-star text, never returned → **Genuine**

## Extending toward the real system

To move from this demo to the full stack on your slides:
- Swap `GradientBoostingClassifier` → `xgboost.XGBClassifier` (same API)
- Swap the lexicon sentiment scorer → NLTK VADER or spaCy
- Wrap `ml/predict.py` in a Spring Boot REST endpoint; call it from a React front end (the JS logic in `demo.html` maps directly onto React state/handlers)
- Replace the synthetic CSV with real purchase/return/review tables from MySQL
- Add JWT auth on the prediction endpoint
